## Using Leonardo
1. **First, the character sheet (#0).**
   - Upload Dadi 2 under **Image Guidance → Character Reference**, strength **Mid** or **High**.
   - Upload your **logo** as **Style Reference**.
   - Generate 4 and pick the best one.
2. **Then every other image.**
   - Use **that character sheet** as Character Reference and the **logo** as Style Reference.
   - Paste the prompt, replace `[AMMA LOCK]` / `[YOUNG AMMA]` / `[STYLE LOCK]` with the paragraphs below, and set the aspect ratio shown next to the filename.
3. **Keep it consistent:** use the same model and preset for every image. If her face drifts, raise the Character Reference strength.
4. **Download the original PNG** (upscale if Leonardo offers it), not a screenshot.
